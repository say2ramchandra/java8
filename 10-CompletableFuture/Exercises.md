# CompletableFuture - Practice Exercises

## Basic Level

### Exercise 1: Creating CompletableFutures
1. Create completed future with value
2. Use supplyAsync() for async computation
3. Use runAsync() for void operations
4. Create exceptionally completed future
5. Manual completion with complete()

### Exercise 2: Basic Transformations
1. Use thenApply() to transform result
2. Chain multiple thenApply() operations
3. Use thenAccept() to consume result
4. Use thenRun() for side effects
5. Understand synchronous vs async variants

### Exercise 3: Combining Futures
1. Use thenCombine() for two futures
2. Use thenCompose() for dependent futures
3. Combine results with allOf()
4. Get first complete with anyOf()
5. Parallel execution of independent tasks

### Exercise 4: Error Handling
1. Use exceptionally() for recovery
2. Use handle() for conditional handling
3. Use whenComplete() for cleanup
4. Chain error handlers
5. Provide fallback values

### Exercise 5: Execution Control
1. Use custom Executor
2. Understand async suffix methods
3. Control thread pool size
4. Handle blocking operations
5. Timeout with orTimeout()
