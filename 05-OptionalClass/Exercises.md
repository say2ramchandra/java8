# Optional Class - Exercises

## Basic
1. Create Optional with value, with null, and empty
2. Check if Optional contains value using isPresent()
3. Get value with orElse() providing default
4. Use ifPresent() to print value if exists
5. Filter Optional based on condition

## Intermediate
6. Chain map() operations on Optional
7. Use flatMap() with method returning Optional
8. Compare orElse() vs orElseGet() performance
9. Use orElseThrow() with custom exception
10. Transform Optional<String> to Optional<Integer>

## Advanced
11. Implement repository pattern returning Optional
12. Handle nested Optionals using flatMap
13. Create validation method returning Optional
14. Process list of Optionals efficiently
15. Build fluent API using Optional chaining
